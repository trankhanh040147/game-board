# Game Board

Three browser games, built entirely by prompting an AI agent — and the receipts.

No game engine was hand-written here. No line of production code was typed by a human. What was
typed is **eight prompts**, and this repository publishes all of it: the games, the prompts, the
tokens, the agent hours, the reasoning, the tests, the dead ends and the fixes.

| Game | What it is | Play | Making-of |
| --- | --- | --- | --- |
| **First Hearth** | A living-world civilisation simulation: one wanderer, an unnamed valley, a hearth | [first-hearth.vercel.app](https://first-hearth.vercel.app) | [making-of](https://game-board-pi.vercel.app/making-of/first-hearth) |
| **Blade & Mount** | A 3D tournament melee game in the browser, in the spirit of Mount & Blade's arena | [blade-and-mount.vercel.app](https://blade-and-mount.vercel.app) | [making-of](https://game-board-pi.vercel.app/making-of/blade-and-mount) |
| **Alien Shooter** | A top-down neon arena survival shooter with zero dependencies and no build step | [alien-shooter-omega.vercel.app](https://alien-shooter-omega.vercel.app) | [making-of](https://game-board-pi.vercel.app/making-of/alien-shooter) |

**The board is live at [game-board-pi.vercel.app](https://game-board-pi.vercel.app)** — it collects all
three games and their making-of exhibits under one roof. The live URL of every deployment is
recorded in [`data/deploy.json`](data/deploy.json).

## The point

The games are the product. The **receipts** are the experiment: what does it actually take to
"vibe code" a game in 2026 — in prompts, tokens, rounds and wall-clock time — and what does the
agent's work look like from the inside while it thinks, tests, breaks and ships?

So the board shows, per game:

- **Every human prompt**, verbatim in the data and translated to English for publication, with its
  timestamp and character count. One is a 20,000-character design brief; one is thirty-eight
  characters long and produced an entire game.
- **Tokens** — input, output and cache-read, reported by the provider, with the honest caveat that
  cache reads dominate and are not fresh work.
- **Rounds** — human turns, lead-agent steps and subagent steps, because "one prompt" hid 99 to 500
  tool-calling steps.
- **Time**, on three clocks that never get conflated: `spanMs` (whole session-family span),
  `durationMs` (wall-clock build window, idle included) and `activeMs` (summed model-active time;
  parallel subagents summed, so it is agent-hours, not elapsed time).
- **How the agents thought** — verbatim reasoning excerpts selected across ideation, architecture,
  debugging and QA.
- **The team** — the subagents each game recruited, their missions, steps and token share.
- **The build** — a milestone arc from plan and scaffold through tests, QA, commits and ship, plus
  the commits themselves where a repository existed.

Everything factual on the site traces back to [`data/telemetry/games.json`](data/telemetry/games.json),
generated by [`scripts/extract-sessions.mjs`](scripts/extract-sessions.mjs) from raw DeepSeek
Harness session logs. The full human-readable report is
[`docs/BUILD-HISTORY.md`](docs/BUILD-HISTORY.md).

heuristics.

## Repository layout

```
.
├── index.html, src/, public/          the Game Board showcase (Vite + TypeScript, no framework)
├── data/
│   ├── registry.json                  game identity, copy, accents, media slots
│   ├── telemetry/games.json           every published metric, prompt, excerpt and milestone
│   └── deploy.json                    live production URLs
├── games/
│   ├── first-hearth/                  TypeScript · Vite · Canvas 2D  (84 tests)
│   ├── blade-and-mount/               TypeScript · Vite · Three.js   (112 tests)
│   └── alien-shooter/                 plain HTML/CSS/Canvas, no build step
├── scripts/
│   ├── extract-sessions.mjs           session logs -> telemetry JSON + BUILD-HISTORY.md
│   └── deploy.sh                      deploy all four Vercel projects
└── docs/
    ├── BUILD-HISTORY.md               the generated making-of report
    └── DEPLOY.md                      Vercel setup, verification, rollback
```

The three games were written independently and are kept independent: each has its own
`package.json` (or none) and its own Vercel project. The board is a separate Vite app at the
repository root.

## Run it locally

Board (the showcase):

```bash
npm install
npm run dev        # http://127.0.0.1:5199
npm run build      # typecheck + production build into dist/
npm run preview    # http://127.0.0.1:5200
```

The games:

```bash
cd games/first-hearth    && npm install && npm run dev    # http://127.0.0.1:5280
cd games/blade-and-mount && npm install && npm run dev    # http://127.0.0.1:5273
cd games/alien-shooter   # open index.html, or: python3 -m http.server 8080
```

## Regenerate the making-of data

The telemetry is derived, never hand-edited. On a machine that has DeepSeek Harness session logs:

```bash
node scripts/extract-sessions.mjs          # rewrites data/telemetry/*.json + docs/BUILD-HISTORY.md
node scripts/extract-sessions.mjs --self-test
```

The extractor is dependency-free (Node + `zstd`), deterministic apart from a `generatedAt`
timestamp, and runs a redaction pass over every published string.

## Deploy

Four independent Vercel projects, all from this monorepo:

| Project | Root directory | Build | Output |
| --- | --- | --- | --- |
| `game-board` | repository root | `npm run build` | `dist` |
| `first-hearth` | `games/first-hearth` | `npm run build` | `dist` |
| `blade-and-mount` | `games/blade-and-mount` | `npm run build` | `dist` |
| `alien-shooter` | `games/alien-shooter` | staged static copy | `dist` |

```bash
npx vercel login
./scripts/deploy.sh            # deploy all four, verify, write data/deploy.json
```

See [`docs/DEPLOY.md`](docs/DEPLOY.md) for the dashboard-equivalent settings, cache headers,
verification steps and rollback.

## Honesty notes

- Prompts in the dataset are verbatim; the English on the site is a translation (originals are
  preserved in the JSON). Seven of the eight prompts were originally Vietnamese.
- Screenshots are the games' own, captured by their test harnesses.
- Wall-clock time includes the human walking away. Agent-active time is not model compute.
- Token totals are provider-reported usage on successful assistant messages: a floor.
- Alien Shooter genuinely had a single prompt and no git history before this repository imported
  it. Nothing was invented to make the story tidier.
